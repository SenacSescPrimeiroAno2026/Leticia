O Flexbox Froggy é um jogo interativo para aprender CSS Flexbox de forma prática e divertida. A ideia é mover sapos até as vitórias-régias usando comandos CSS. Ele é muito usado por iniciantes em front-end porque transforma conceitos visuais de layout em desafios simples.
